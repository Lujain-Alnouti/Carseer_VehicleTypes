# Carseer_VehicleTypes

This project consists of a .NET Core Web API and an Angular frontend application, both included in the same solution

Application Structure:
-- Backend: .NET Core Web API (http://localhost:5118/swagger)
-- Frontend: Angular (http://localhost:4200)

The application is fully Dockerized as required
Run using Docker
From the root directory of the project, execute:
docker compose up --build
   - This command will build and start both the API and frontend containers
